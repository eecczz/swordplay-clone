# swordplay-clone

wii swordplay 재현  
(swordplay 리포지토리를 이어서 작업)

wii swordplay 게임을 모션인식 컨트롤러가 아닌 마우스 조작으로 재현하여 PC 게임으로 만들어 보았습니다.  
캐릭터의 공격 모션과 그에 따른 무기의 움직임이 플레이어가 마우스 조작으로도 실재감을 느낄 수 있도록 하는 데 신경 썼습니다.  
GitHub Pages 배포를 통해 web으로 간단히 플레이해볼 수 있습니다.

플레이하기:  
https://eecczz.github.io/swordplay-clone/

## Third-party Asset Store package

This repository does not include the third-party Asset Store package located at:

```text
Assets/AssetStoreReady/FImpossible Creations
```

The package was removed from GitHub history and is ignored by `.gitignore` because it is a paid/proprietary Asset Store asset and should not be redistributed through this repository.

To run the Unity project after cloning:

1. Obtain the required FImpossible Creations Asset Store package through a valid license.
2. Import or restore it locally into:

```text
Assets/AssetStoreReady/FImpossible Creations
```

3. Open the project in Unity and allow Unity to reimport assets.
